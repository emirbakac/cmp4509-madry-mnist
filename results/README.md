# Sonuç durumu

Henüz bilimsel eğitim/değerlendirme sonuçları yok. Smoke testi yalnızca kod zincirini doğrular.

Notebook çalıştığında kendi sonuç klasörüne per_seed.csv, summary.csv, summary.md,
accuracy.png ve training_curves.png üretilir. Eğitimde history.csv; değerlendirmede
metrics.csv, evaluation.json, per_example.csv ve examples.png kaydedilir.
Rapora aynı protokolün 0, 1, 2 eğitim seed'lerini koyun; örnek standart sapması ddof=1.
Tek seed'in standart sapması tanımsızdır. Smoke/pilot/main sonuçlarını birleştirmeyin.
